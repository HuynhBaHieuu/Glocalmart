Tài liệu API

Gửi header X-API-Key: <khóa> trong mọi request. Phản hồi dạng JSON.

  • GET /api/san-pham/

    Danh sách sản phẩm. Lọc: ?ma=SP-0001, ?danh_muc=DM001, ?q=sữa, ?trang_thai=DANG_BAN, ?page=2

  • GET /api/san-pham/<ma_sp>/

    Chi tiết một sản phẩm theo mã.

  • GET /api/ton-kho/<ma_sp>/

    Tồn kho thời gian thực của sản phẩm.

  • GET /api/danh-muc/

    Danh sách danh mục đang hoạt động.

Ví dụ

curl -H "X-API-Key: glm_xxx" \
  "{{ base }}san-pham/?danh_muc=DM001"

Thiếu hoặc sai khóa → 401 Unauthorized.
